# Documentation

Guides for running and extending the start page. The project is plain HTML, CSS and JavaScript with Vue loaded from a CDN, so there is no build step.

| Document | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Running the page, using it as a browser home page, project layout |
| [Architecture](architecture.md) | Load order, state and storage, lazy widget loading, drag and drop |
| [Widgets](widgets.md) | Adding a widget, the widget API, built-in widgets |
| [Localization](localization.md) | Adding a language and widget language packs |
| [Customization](customization.md) | Search engines, theme, sizes, backup and reset |
